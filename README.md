# Kavaro Desktop Application 🚀

هذا المشروع هو تطبيق مكتبي متطور تم بناؤه باستخدام لغة **C++** وإطار عمل **Qt Framework**، مخصص لإدارة البيانات، الطلبات، والتقارير المالية بشكل احترافي وسلس.

---

## 🛠 التقنيات المستخدمة (Technologies)

*   **Language:** C++ (Modern C++)
*   **Framework:** Qt Widgets (للحصول على واجهة مستخدم سريعة ومتوافقة مع أنظمة التشغيل المختلفة).
*   **Build System:** CMake.
*   **Resources:** Qt Resource System (.qrc) لإدارة الصور والأيقونات.

---

## 📂 تقسيم الملفات (Project Structure)

المشروع منظم بطريقة برمجية نظيفة (Clean Architecture) تعتمد على المكونات القابلة لإعادة الاستخدام:

```text
Kavaro_decktop/
├── src/                    # الكود المصدري الأساسي
│   ├── main.cpp            # نقطة انطلاق التطبيق (Entry Point)
│   ├── Auth/               # ملفات تسجيل الدخول والتحقق (Authentication)
│   └── Screens/            # الشاشات الأساسية للتطبيق
│       ├── Dashboard/      # لوحة التحكم الرئيسية
│       │   ├── Pages/      # الصفحات الفرعية (Overview, Orders, Settings, etc.)
│       │   └── Components/ # المكونات المشتركة (Sidebar, TopNavbar, Notifications)
│       └── Financial/      # الشاشات المتعلقة بالبيانات المالية
├── assets/                 # الصور، الأيقونات، والخطوط
├── qml/                    # ملفات QML (في حالة استخدام Qt Quick)
├── CMakeLists.txt          # ملف إعدادات بناء المشروع
└── qrc.qrc                 # ملف موارد Qt للصور والأصول
```

---

## ⚙️ كيف يعمل التطبيق؟ (How it Works)

1.  **نظام التنقل (Navigation):** يستخدم التطبيق `Sidebar` (شريط جانبي) للتنقل بين الصفحات المختلفة داخل الـ `FinancialDashboard`.
2.  **المكونات (Components):** كل جزء في الواجهة مصمم كمكون مستقل (مثل `TopNavbar` أو `NotificationsSidebar`) مما يسهل عملية التعديل والتطوير.
3.  **إدارة الصفحات:** يتم تبديل الصفحات في منطقة العرض الرئيسية بناءً على اختيار المستخدم من القائمة الجانبية.
4.  **STL Uploads:** التطبيق يدعم ميزة فريدة لرفع ملفات STL (غالباً ما تستخدم في الطباعة ثلاثية الأبعاد) وإدارتها.

---

## 🚀 كيفية التشغيل (Setup & Run)

للتشغيل، تحتاج إلى تثبيت **Qt SDK** و **CMake**:

1.  قم بفتح المشروع باستخدام **Qt Creator**.
2.  اختر `CMakeLists.txt`.
3.  قم بعمل **Build** ثم **Run**.
